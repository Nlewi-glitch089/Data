# Data Quality Analysis — Planning and Learning Materials

This repository preserves planning material and learning resources for an agentic data-quality analysis project. It is not the current runnable application.

## What is in this repository

- `brayden/` — a separate project/work folder with its own application files.
- `data-analysis-tutorial/` — tutorial and reference material related to the data-analysis project.

The original project brief and learning material describe a proposed platform for uploading datasets, measuring quality issues, and presenting recommendations. Treat those feature descriptions as project goals unless the code in the relevant folder demonstrates that they are implemented.

## Current application repository

The current Next.js application is maintained separately:

[Open the Data Quality Analysis application repository](https://github.com/Nlewi-glitch089/Data2-)

See that repository's README for the current implementation, local setup, environment variables, and Vercel deployment instructions.

## Working with this repository

This repository is a collection of project materials rather than a single application with one root-level install command. Open the folder you intend to work with and follow any setup instructions contained there.
